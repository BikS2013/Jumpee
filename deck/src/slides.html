BikS2013 · project notes

Your desktops
have names
now.

Jumpee is a small macOS menu bar app that names your Mission Control desktops, jumps you between them from the keyboard, and prints the name of the one you are on straight onto the wallpaper.
A product tour · what it does, how to install it, how to configure it
Version 1.8.0 · September 2026
Introduction
Mission Control gives you numbers, not names.
The symptom

Desktop 3 is a guess

macOS labels spaces Desktop 1, 2, 3 and stops there. Nothing on screen tells you that Desktop 3 holds the mail and Desktop 5 is the build machine.

The gap

Renaming is not a feature

There is no supported way to name a space — no public API, no System Settings switch, no checkbox anywhere in Mission Control.

The friction

Windows land in the wrong place

Sending a window to another desktop means dragging it to the screen edge and waiting, or enabling a Mission Control shortcut most people never touch.

Jumpee closes all three. It reads the space you are on, keeps a name against it, and gives you a keyboard route to every other one.

Section 01
01 · Naming
Type a name. It sticks to the space, not the position.

macOS identifies a space by a stable internal ID. Jumpee stores your name against that ID — so when you drag desktops around in Mission Control, the names travel with what is actually on them.

  • Return renames, Escape cancels — a focused panel, not a stacked alert.
  • Remove Name clears a desktop back to Desktop 2.
  • Renaming applies to the desktop you are on right now.
  • Names are written to the config file the moment you confirm.

Section 01
01 · Windows
Send the front window to another desktop — without dragging.
1

Focus the window you want to move

Click it once. Jumpee always acts on the frontmost window of the frontmost app.

2

Open Jumpee and pick Move Window To…

From the dropdown, from the submenu, or with ⇧⌘1–⇧⌘9 while the list is open. A global hotkey can open the same list at your cursor.

3

Pick the destination

The window moves and your view follows it. The current desktop is left out of the list — you cannot move a window onto the desktop you are already on.

Two things to know. The system's Move window to Desktop N shortcuts must be enabled first — Jumpee reports their status in Settings › Advanced. And on macOS 15 and later the move always brings you along: "move without following" is a platform limitation, not a setting. Windows that cannot move — fullscreen, or assigned to all desktops — are simply left alone.
Section 01
01 · Windows
Keep one window above all the others.

Focus a window, press the pin shortcut, and it stays floating above everything else — including windows belonging to other apps.

  • Press ⌃⌘P again on the same window to unpin it.
  • Several windows, from different apps, can be pinned at once.
  • The menu item changes with the focused window: Pin Window on Top or Unpin Window.
  • Pin state lives in memory only — quitting Jumpee releases every window it was holding.

Section 02
02 · Displays
Each display keeps its own set of desktops.
The list
Shows only the spaces belonging to the display you are working on — not a flattened list of everything.
The numbers
⌘1–⌘9 follow that display's own numbering, starting at 1 on each screen.
The watermark
Appears on the display holding the active space, and repositions when you move to the other one.
The indicator
Same rule — the keyboard language follows the active display, with the menu bar height measured per screen so notched and external displays both sit correctly.
Plugging in
Connecting or disconnecting a display rebuilds the menu and the overlays for the new layout. Nothing restarts.
Window moves respect the same topology: a window is sent to a desktop on the active display, using the global numbering the system shortcuts expect.

03 · Setup 1 of 3
Grant Accessibility. Nothing switches without it.

Jumpee never reaches into another app. To change desktop, it asks macOS to run the system's own shortcut — and synthesising that keystroke sits behind Accessibility, which macOS will not let an app grant to itself.

1

Open the pane

System Settings › Privacy & Security › Accessibility.

2

Switch Jumpee on

If it is not listed, click + and add /Applications/Jumpee.app.

3

Or follow the prompt

Jumpee asks on first launch and takes you straight there.

Privacy & Security › Accessibility
J Jumpee
T Terminal

Switching desktops and moving windows both need this one permission.

Section 03
03 · Setup 2 of 3
Turn on Switch to Desktop 1–9.

There is no public API for changing desktop. Jumpee presses macOS's own ⌃1…⌃9 shortcuts — and those ship switched off.

1

Open the shortcut list

System Settings › Keyboard › Keyboard Shortcuts › Mission Control.

2

Tick the desktop shortcuts

Switch to Desktop 1 through Switch to Desktop 9.

3

Leave them alone afterwards

Changing them to another key breaks navigation — Jumpee expects the system defaults.

Keyboard Shortcuts › Mission Control
Switch to Desktop 1⌃1✓
Switch to Desktop 2⌃2✓
Switch to Desktop 3⌃3✓
Switch to Desktop 4⌃4—

Skip these and the list still draws correctly — but clicking a desktop goes nowhere.

03 · Setup 3 of 3
Screen Recording is only for pinning.
Required — for pinning only

Screen Recording

Pinning works from a captured image of the window, so macOS gates it behind Screen Recording. Leave it off and everything else still works; the first time you pin, Jumpee asks and opens the pane for you.

System Settings › Privacy & Security › Screen Recording

Optional

Launch at login

Jumpee does not install itself as a login item. If you want it waiting at every start, add it yourself — it is one toggle in System Settings › General › Login Items.

Until then, start it from Spotlight whenever you want it.

The whole setup in one line: one permission for naming, switching and the overlays, a second only for pinning, and one set of system shortcuts that macOS keeps switched off by default.

Section 04
04 · Shortcuts
Record a shortcut by pressing it.

No checkbox-and-text-field fiddling. Click the control, press the chord you want, and it is captured whole — modifiers and all, including named keys like Space, Return, Tab and Escape.

  • Escape with no modifiers cancels recording.
  • A shortcut needs at least one modifier, a key from the supported set, and no clash with the other two.
  • Applying it re-registers the hotkey immediately — no restart, no manual reload.
  • Every row has its own reset, and there is one Restore Defaults for all three.
  • Rows for disabled features stay visible, greyed out, so you can see what is available.
Shortcuts
Open Jumpee⌘ JReset
Move Current WindowRecording…Reset
Pin or Unpin Window⌃ ⌘ PReset

The third row is greyed out because Pin windows on top is switched off in General.

Section 04
04 · Advanced
Advanced tells you what macOS is holding back.
Status

Three checks, one screen

  • Accessibility — granted or not, with a way through to the pane.
  • Mission Control shortcuts — whether Switch to Desktop 1–9 are detected, plus a Review Shortcuts… button.
  • Screen Recording — the permission pinning depends on.

No guessing why a feature is quiet.

The file

Reveal and reload

  • Reveal config file opens the JSON in Finder.
  • Reload Now re-reads it and re-registers every hotkey — no restart.
  • Everything the Settings panes do lands in that same file, so hand-edits and UI edits never diverge.

Edited by hand and it did not take? Reload Now is the answer.

Section 04
04 · Configuration
Everything the app knows, in one file.
{
  "hotkey":        { "key": "j", "modifiers": ["command"] },
  "moveWindow":    { "enabled": true },
  "pinWindow":     { "enabled": true },
  "overlay": {
    "enabled": true, "fontSize": 72, "fontWeight": "bold",
    "opacity": 0.15, "position": "top-center",
    "textColor": "#FF0000", "margin": 40
  },
  "showSpaceNumber": true,
  "spaces": { "42": "Mail & Calendar", "15": "Development" }
}
1

~/.tool-agents/jumpee/config.json

The folder is created 0700 and the file 0600. It is written for you on first run and it is the only configuration method — no environment variables, no command-line flags.

2

Spaces are keyed by ID, not position

"42" is the space's stable internal ID. That is why names survive a reshuffle — and why you should rename from the menu rather than editing keys by hand.

3

Coming from an older build?

Legacy configs are migrated automatically — position-keyed spaces to ID-keyed, and the old ~/.Jumpee/ folder to the new path on first launch.

05 · Use cases
Three places it earns its keep.
01

One machine, four jobs

Comms, development, terminal, browser — four desktops, four names, no memorising. ⌘J then the number, from inside any app, without losing your place.

The menu bar answers "where am I?" before you have to ask.

02

Presenting and screen sharing

Your audience sees the space name printed on the desktop you are sharing, and the input-source pill stops the mid-sentence "why is my typing in Greek?" moment before it happens.

Both overlays are click-through, so nothing you demo is blocked.

03

A reference that must not vanish

Pin the document, dashboard or call transcript you are working from above everything else, then edit underneath it. Unpin when you are done — or quit, and Jumpee releases it for you.

Several pinned windows at once, from different apps.

It suits anyone who already thinks in desktops but cannot remember what is on each one — and anyone whose work mixes two keyboard languages across two screens.
Section 05
05 · Worth knowing
What it does not do.
LimitWhy
Nine desktops per displaySwitching rides on the system's ⌃1–⌃9 shortcuts, so there is nothing beyond the ninth.
Moving a window always follows itmacOS 15 and later force the view across with the window. Not a setting, a platform rule.
Space detection rests on private APIsmacOS offers no public way to read the current space, so Jumpee uses undocumented CoreGraphics calls. A future release could break them.
The watermark shows the current space onlyPrinting each name into the Mission Control thumbnails is not reachable on current macOS.
Pins are forgotten at quitPin state is kept in memory by design, so nothing is left floating after Jumpee exits.
The ⌘M default clashes with MinimizeChange it to ⇧⌘M — a known trade-off recorded in the project's own notes.
